# 선덕 서바이벌

[웹에서 플레이](https://changminchoi.github.io/sundeok-survival-web/) · 버전 1.1.3

Unity WebGL 정적 배포 파일입니다. 키보드, 마우스 드래그, 터치 및 게임패드를 지원합니다.
진행은 이 사이트의 브라우저 저장소에 저장되며 다른 앱이나 기기와 자동 동기화되지 않습니다.

`site/`에는 웹 실행 파일만 포함합니다. Unity 프로젝트 소스, 개인 저장 데이터와 서명 키는 포함하지 않습니다.
대용량 데이터는 `web-v1.1.3` GitHub Release의 `WebGL.data.unityweb`에 보관하며,
GitHub Actions가 SHA256을 검증한 뒤 GitHub Pages에 함께 배포합니다.

한글 글꼴 라이선스: [Noto Sans CJK OFL](site/NotoSansCJK-OFL.txt).
